HOW TO UPDATE YOUR GITHUB REPOSITORY
1. Open https://github.com/terasynctech/royal-biryani
2. Open index.html, click the pencil (Edit) icon, replace all its contents with the new index.html, then Commit changes.
3. Repeat for styles.css and app.js.
4. Wait 2–5 minutes and open https://terasynctech.github.io/royal-biryani/
